Guac Bridge includes a private Windows App Runtime for its native WinUI manager.

Setup installs the UI runtime files with Guac Bridge. No separate runtime download,
registration, or system-wide runtime installation is needed. The private runtime
is removed when Guac Bridge is uninstalled.

Closing the manager window keeps the tray and bridges running. Use the tray icon
or Start menu to reopen it. Use Exit tray to quit the tray, keeping bridges running.

The manager requires Windows 11 / Windows Server 2025 or newer. Bridges and the
tray host remain available on earlier Windows versions.
